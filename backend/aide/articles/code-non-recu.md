Voici dans l'ordre ce qu'il faut essayer.

## 1. Patiente un instant

L'envoi peut prendre **quelques secondes**, parfois un peu plus sur le réseau mobile. Ne demande pas dix codes à la suite : seul le dernier fonctionne.

## 2. Vérifie ton numéro ou ton adresse

Une faute de frappe est la cause la plus fréquente. Pour un numéro, vérifie l'indicatif du pays.

## 3. Cherche dans les courriers indésirables

Si tu as choisi l'e-mail, regarde dans les **spams** (courrier indésirable). L'expéditeur est EduKora.

## 4. Demande un nouveau code

Le code n'est valable que quelques minutes. S'il a expiré, utilise « Renvoyer le code ».

## 5. Change de moyen

Essaie avec l'autre option : e-mail à la place du SMS, ou Google.

## Toujours rien ?

Écris-nous sur WhatsApp au {{whatsapp}} en indiquant le numéro ou l'adresse que tu utilises : voir [Contacter le support](/aide/contacter-le-support).
