## Réinitialiser le code parent

1. Quand le code parent est demandé, choisissez « Code oublié ? ».
2. Appuyez sur « Envoyer le code de vérification ». Un **code à 6 chiffres** est envoyé par SMS ou par e-mail, selon le moyen avec lequel le compte est connecté.
3. Saisissez ce code. L'ancien code parent est alors **supprimé**.
4. Définissez-en un **nouveau**.

## Vous ne recevez pas le code de vérification ?

Voir [Je ne reçois pas mon code de connexion](/aide/code-non-recu) : les mêmes vérifications s'appliquent (spams, quelques secondes d'attente, numéro correct).

## Code d'un enfant oublié

Le parent peut rouvrir le profil de l'enfant avec le code parent. Voir [Profils et code parent](/aide/profils-et-code-parent).
