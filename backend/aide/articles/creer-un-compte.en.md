There is **no password** to remember.

## Logging in

1. Go to the [login](/connexion) page.
2. Enter your phone number or e-mail address, or choose Google.
3. If you chose phone or e-mail, you receive a **code**. Type it in.

If this is your first login, your account is created automatically: there is no separate sign-up form.

## Good to know

- The code is only valid for a few minutes. If it expires, ask for a new one with "Resend the code".
- Not receiving anything? Read [I don't receive my code](/aide/code-non-recu).
- Always use **the same method** (same number or same address) to get back into your account.
