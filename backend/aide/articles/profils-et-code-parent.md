## Un profil par enfant

Dans un même compte, chaque enfant a **son profil** : sa progression, son examen et son abonnement sont séparés.

## Pourquoi un code parent ?

Sans code, chaque enfant peut voir les abonnements des autres et ouvrir leur profil. Un **code parent** (4 chiffres) garde cela pour vous : les actions réservées au parent (autres enfants, sécurité des profils, ajout d'un enfant) demandent alors ce code.

## Le mettre en place

Dans [Mes accès](/mes-acces), ouvrez la section « Sécurité des profils » et suivez les étapes.

## Protéger le profil d'un enfant

Un profil peut aussi être protégé par son **propre code à 4 chiffres** : il faut le saisir pour l'ouvrir.
