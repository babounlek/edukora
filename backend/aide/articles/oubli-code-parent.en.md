## Resetting the parent code

1. When the parent code is asked, choose "Forgot the code?".
2. Press "Send the verification code". A **6-digit code** is sent by SMS or e-mail, depending on how the account is connected.
3. Enter this code. The old parent code is then **deleted**.
4. Set a **new** one.

## Not receiving the verification code?

See [I don't receive my login code](/aide/code-non-recu): the same checks apply (spam, a few seconds' wait, correct number).

## A child's forgotten code

The parent can reopen the child's profile with the parent code. See [Profiles and parent code](/aide/profils-et-code-parent).
