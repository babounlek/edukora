Un **cadenas** ou un bouton grisé veut dire que ce contenu demande l'abonnement. Ce n'est pas un bug.

## Ce qui reste gratuit

- Tous les **cours**.
- Certains **corrigés d'annales**.
- Les **quiz d'essai**.

Voir le détail dans [Gratuit ou payant ?](/aide/gratuit-ou-payant).

## Tu as payé mais c'est encore verrouillé

1. Ouvre [Mes paiements](/mes-paiements) : si le paiement est « en vérification », l'accès n'est pas encore actif. Voir [Mon paiement est en vérification](/aide/paiement-en-verification).
2. Si le paiement est validé, vérifie dans [Mes accès](/mes-acces) que le **bon enfant** et le **bon examen** sont sélectionnés : l'abonnement est lié à un profil et à un examen.
3. Recharge la page ou reconnecte-toi.
4. Toujours verrouillé ? Écris-nous sur WhatsApp au {{whatsapp}} avec ton code d'assistance (voir [Contacter le support](/aide/contacter-le-support)).
