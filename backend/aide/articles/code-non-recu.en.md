Here is what to try, in order.

## 1. Wait a moment

Sending can take **a few seconds**, sometimes a bit longer on the mobile network. Don't ask for ten codes in a row: only the latest one works.

## 2. Check your number or address

A typo is the most common cause. For a phone number, check the country code.

## 3. Look in your junk mail

If you chose e-mail, check your **spam** folder. The sender is EduKora.

## 4. Ask for a new code

The code is only valid for a few minutes. If it expired, use "Resend the code".

## 5. Change method

Try the other option: e-mail instead of SMS, or Google.

## Still nothing?

Write to us on WhatsApp at {{whatsapp}} with the number or address you use: see [Contacting support](/aide/contacter-le-support).
