## Mesures

- Poids / requêtes : sur toute la session mobile dans le même onglet (SPA), 250 requêtes et environ 663 Ko transférés selon `performance.getEntriesByType('resource')` (réseau local non bridé, cache non vidé). - Page de cours "combinaison" : hauteur 8 680 px (environ 10,7 écrans mobiles) ; pastille "≈ 2 min restantes" affichée pendant que la fiche annonce "30 min".
- Temps de reprise (M8) : quiz quitté -> retour Aujourd'hui -> "Reprendre" : environ 3 taps et moins de 10 s ; bouton principal de l'accueil en haut, bloc "Quiz en cours" visible après environ 2 écrans de défilement.

- Épreuve inédite : 6 exercices / 17 questions ; 7 cochées ; "Temps utilisé : 1 min 3 s".
- Erreurs console : 2 occurrences de "An unknown error occurred when fetching the script".
- Sons : un module de retours audio existe dans le code chargé (présence d'`AudioContext` dans `retours-*.js`) et un réglage "Sons et vibrations" existe dans Mon compte ; je n'ai pas pu écouter, donc je ne sais pas ce qui s'entend.
